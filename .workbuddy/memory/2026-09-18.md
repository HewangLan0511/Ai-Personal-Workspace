## 第三批：原语层别名对齐 + 缺口口径收紧（同日晚些时候）

### 1) 根因：并入的 CSS 不是最终裁判

`components/ui/primitives.css` 在 `main.ts` 里的顺序是 **tokens → motion-tokens → base.css → primitives.css**。
也就是说 `pw-*` 原语层的同族声明**覆盖**设计稿的 `.card/.btn/.chip/.input/.avatar/.row-item/.drawer/.t-page…`。
"设计稿组件层逐字并入 23/23 全绿"的**同时**，页面真实渲染值仍由原语层决定 —— 这就是
"设计接了但看起来不一样"的根因。**教训：做视觉融合必须问"这些选择器的 computed 值最终由谁决定"。**

### 2) 实测 10 处漂移（改前 → 改后）

`.pw-t-section` 16px → `--fs-section` 15px；`.pw-t-card` 15px → `--fs-card` 14px；
`.pw-t-*` 缺 `--lh-*`/`--ls-*`；`.pw-t-page` 缺 `--font-display` 且字距 -0.01em → -0.014em；
`.pw-t-label` 缺 `text-transform:uppercase`；`.pw-card` 内距 16px → `--pad-card` 20px；
`.pw-card--lg` 20px → `--pad-card-lg` 24px；`.pw-card--hoverable:hover` 缺 `translateY(-1px)`；
`.pw-avatar` `--brand-50/600` → `--brand-100/700`；`.pw-grid` 12px → `--gap-card` 20px。
另有：`.pw-btn` 多一条透明边框、`.pw-btn--lg` 15px→`--fs-card`、`--primary` 用 `#fff`→`--text-on-brand`、
`--danger` 用 `--danger-text`、`--secondary` 缺 `--shadow-xs`、**全部交互件缺 transition**、
`.pw-scrim`/`.pw-drawer` 缺 `fadeIn`/`drawerIn` 且 z-index 40/41 → `--z-modal`/`--z-drawer`(60)、
`--shadow-floating` → `--shadow-lg`。选择器**一律未动**（T4f 不受影响）。
`--f-space-*`→`--space-*`、`--radius-controls`→`--r-md`、`--f-radius-3`→`--r-lg`。
