# 05 · 阶段指令 · 第二阶段：软件管理系统

**优先级**：P0 · MVP
**前置**：`04-阶段指令-基础框架.md`
**目标一句话**：让工作台"认识"用户电脑里的软件。

**验收一句话**：用户能把一个 exe 加进工作台，点一下就能打开它。

---

## 目标

建立软件注册表 + 启动能力 + 分类检索。这是工作模式引擎的**数据基础**。

---

## 必须实现

### 1. 软件注册（增删改查）
- 添加软件，字段严格按 `03-数据契约与接口规范.md` 3.2.3。
- **添加方式（至少支持前两种）**：
  1. 选择可执行文件（文件选择器，过滤 `.exe .lnk .bat`）
  2. 从"已安装软件"扫描（读注册表 `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall` + `HKCU` 同名路径，取 `DisplayName` / `DisplayIcon` / `InstallLocation`）
  3. 拖拽文件到窗口（V1.1 可选）
- **自动补全**：选中 exe 后自动填充 `name`（从文件属性 `FileDescription` 或文件名）、`icon`（提取 exe 内嵌图标并缓存到本地）。
- 编辑、删除（软删除，写 `deleted_at`）。
- 分类：预置 `开发 / 浏览器 / 办公 / 媒体 / 游戏 / 其他`，支持用户新增自定义分类。
- 搜索：按名称/分类模糊匹配。

### 2. 启动软件
```
点击软件卡片
   ↓
core 校验 path 存在
   ↓
调用系统 API 启动（见 ADR-001）
   ↓
更新 launch_count / last_used_at
   ↓
发布 APP_OPENED { appId, pid, hwnd }
   ↓
UI 标记为"运行中"
```

- **工作目录**：启动时把 `cwd` 设为 exe 所在目录（很多程序依赖这个）。
- **启动失败处理**（必须有）：
  - 路径不存在 → 提示"文件不存在：<path>，是否重新指定？"
  - 权限不足 → 提示"需要管理员权限运行"
  - 已在运行 → 优先激活已有窗口，不要重复拉起（可配置开关）
- **超时**：15s 内未拿到 pid 视为失败。

### 3. 运行状态检测
- 定时（默认 5s）检查已启动进程是否存活 → 更新 UI 状态。
- 进程退出 → 发布 `APP_CLOSED`，UI 取消"运行中"标记。
- 检测方式：按 `pid` 轮询存活；同时支持按进程名反查（用于识别用户手动启动的程序）。

### 4. 常用软件排序
- 默认按 `launch_count DESC, last_used_at DESC`。
- Dashboard 的"常用软件"Widget 直接消费这个排序。
- 支持用户置顶（`pinned` 字段，可在本阶段给 `apps` 表加 `pinned INTEGER DEFAULT 0`）。

### 5. UI 页面
- 软件库页面：卡片网格（图标 + 名称 + 启动按钮 + 右键菜单）
- 列表视图切换（表格：名称/路径/类型/启动次数/最后使用）
- 空状态引导："还没有添加软件，点这里开始"
- 分类侧栏 + 搜索框

## 技术要点

### 图标提取（Windows）
- exe/dll/lnk → 用 `SHGetFileInfo` 或 `ExtractIconEx` 提取。
- 输出 PNG（建议 64×64 和 128×128 两档）缓存到 `%APPDATA%/PersonalWorkspace/icons/<hash>.png`。
- **不要**把图标二进制塞进数据库（违反数据轻量化）——只存路径。

### 快捷方式解析
- `.lnk` 需要解析出真实目标路径：`IShellLink` + `IPersistFile`。
- 解析失败则保存 lnk 本身路径，启动时交给系统处理。

### 已安装软件扫描
- 注册表读取需处理 32/64 位视图（`KEY_WOW64_64KEY` / `KEY_WOW64_32KEY`）。
- 去重规则：`DisplayName + InstallLocation` 相同视为同一软件。
- 扫描结果**先展示给用户勾选**，不要自动全部入库。

## 验收标准

| # | 验收项 | 方法 |
|---|--------|------|
| 1 | 添加软件 | 选一个 exe → 卡片出现，图标正确 |
| 2 | 启动软件 | 点卡片 → 目标程序在 5s 内启动 |
| 3 | 启动失败提示 | 把 path 改成不存在 → 出现可读提示，不是崩溃 |
| 4 | 状态同步 | 手动关掉程序 → 5s 内卡片取消"运行中" |
| 5 | 分类与搜索 | 改分类、搜关键词都能正确过滤 |
| 6 | 排序 | 启动次数多的排在前面 |
| 7 | 扫描 | 能列出本机已安装软件，用户可勾选入库 |
| 8 | 持久化 | 重启应用后软件列表、分类、排序保持不变 |

## 禁止事项

- ❌ 不要存软件本体或大图标二进制进数据库
- ❌ 不要在 UI 线程做注册表扫描（会卡界面）——放 Python sidecar 或 Rust 异步任务
- ❌ 不要硬编码 Program Files 路径
- ❌ 不要用 `shell=True` 拼字符串启动进程（命令注入风险）
