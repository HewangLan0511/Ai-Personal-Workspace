# 09 · 阶段指令 · 第六阶段：学习成长模块

**优先级**：V2
**前置**：`08-AI助手`（需要 AI 生成路线）
**定位一句话**：**AI 规划，用户执行，系统提醒。**

---

## 核心原则（必须遵守）

> **AI 提供建议，用户决定状态。**
> AI **不允许**自动修改学习进度、自动勾选完成、自动修改路线。

这是产品的信任基础。违反了，这个模块就变成了"AI 自嗨的进度条"。

---

## 必须实现

### 1. 目标输入
- 用户输入自然语言目标，例如：*"学习计算机视觉并完成项目。"*
- 表单字段：标题（必填）、描述（可选）、期望完成时间（可选）、优先级。
- 数据表：`learning_goals`。

### 2. AI 生成学习路线
```
用户输入目标
    ↓
调 AI（prompt: roadmap_generate.md）
    ↓
返回结构化路线（必须让模型输出 JSON，不是自由文本）
    ↓
以"建议态"展示给用户
    ↓
用户可：确认 / 编辑节点 / 增删 / 重新生成
    ↓
确认后写入 learning_roadmap
```

**必须要求模型输出严格 JSON**：
```json
{
  "goal": "学习计算机视觉并完成项目",
  "nodes": [
    { "title": "Python 基础", "order": 1, "estimated": "2周", "resources": ["..."] },
    { "title": "OpenCV", "order": 2, "estimated": "3周", "resources": ["..."] },
    { "title": "CNN", "order": 3, "estimated": "3周" },
    { "title": "深度学习", "order": 4, "estimated": "4周" },
    { "title": "项目实践", "order": 5, "estimated": "3周" }
  ]
}
```
- 解析失败 → 降级为文本展示 + 手动录入，**不要让用户看到 JSON 解析错误**。

### 3. 学习状态管理（用户手动）
- 每个路线节点状态：`未开始 / 学习中 / 完成 / 暂停`
- 用户主动更新，可以附一条备注（写 `learning_updates`）。
- 目标整体进度 = 已完成节点 / 总节点（展示为进度条）。
- Dashboard 的"学习路线"Widget 消费这个数据。

### 4. AI 的作用（严格限定）
允许：
- 路线优化建议（"建议在 CNN 前先补 线性代数"）→ 以建议卡片展示，需用户点击"采纳"
- 学习建议（根据当前节点推荐资料方向）
- 阶段总结（根据用户备注生成复盘草稿）

禁止：
- 自动改状态
- 自动改路线结构
- 自动勾选完成

### 5. 提醒机制
- 检测"长期未更新"：默认阈值 **30 天**（可配置，见 `config.learning.remind_after_days`）。
- 触发提醒：
  - 应用内：Dashboard + 学习页的提示条
  - 系统通知（可选）：`"「学习计算机视觉」已 30 天未更新，是否继续？"`
- 提醒提供三个动作：**继续 / 暂停 / 归档**。
- 同一目标提醒频率限制：最多 7 天一次（避免骚扰）。

### 6. 项目管理（同章节交付）
- 项目实体：名称、角色、简介、技术栈、起止时间、状态、关联目录。
- 项目可与工作模式绑定：*"进入开发模式时自动关联 my-app 项目"*（这是本模块与核心的联动点，优先做）。
- 项目可与学习目标关联：完成某项目 = 达成某学习目标。

### 7. UI
- 学习页：目标列表（卡片，带进度环）+ 目标详情（路线时间轴）
- 路线可视化：竖向时间轴，节点带状态色（未开始灰 / 学习中蓝 / 完成绿 / 暂停黄）
- 项目页：项目卡片 + 详情抽屉

---

## 验收标准

| # | 验收项 | 方法 |
|---|--------|------|
| 1 | 生成路线 | 输入"学习计算机视觉并完成项目" → 生成 5 个左右合理节点 |
| 2 | 路线可编辑 | 增删节点、改名、调顺序都能保存 |
| 3 | 状态更新 | 用户手动改状态，进度条实时更新，重启后保持 |
| 4 | 提醒 | 把 `remind_after_days` 改成 0 天 → 立刻触发提醒 |
| 5 | 提醒动作 | 点"暂停"后状态变 paused 且不再提醒（7 天内） |
| 6 | AI 只建议 | AI 生成的建议不会直接改动任何进度数据 |
| 7 | 联动 | 项目能绑定到工作模式，进入模式时侧栏显示当前项目 |
| 8 | 解析降级 | 模型返回非法 JSON 时，界面仍可用，不报错 |

## 禁止事项

- ❌ 不允许 AI 自动修改用户的学习状态
- ❌ 不要把 AI 输出直接展示为"事实"（必须标记为"AI 建议，待确认"）
- ❌ 不要做强制提醒（用户关不掉）
- ❌ 不要把所有学习数据塞进一个 JSON 字段（必须结构化到表）
