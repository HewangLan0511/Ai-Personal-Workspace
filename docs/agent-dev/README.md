# Personal Workspace · Agent 开发指令集

本目录是把两份项目计划书（`《…》Agent开发执行计划书 V1.0.txt` 与 `…项目设计计划书 V1.0.txt`）转化为**可直接交给开发 Agent 执行**的指令文件。

## 怎么用

**给开发 Agent 的最短路径**：

```
第一步：读 AGENTS.md（全局规则 + 阶段索引）
第二步：读 01 / 02 / 03（上下文 / 架构 / 数据契约）—— 只读一次，长期有效
第三步：读当前阶段的指令文件（例：06-阶段指令-工作模式引擎.md）
第四步：按 ②出计划 → ③实现 → ④自检 → ⑤交付 的流程干活
第五步：交付前对照 13-验收清单与禁止事项.md
```

## 阶段推进顺序（不要跳）

```
MVP（必须先全部完成）
  04 基础框架 → 05 软件管理 → 07 窗口管理 → 06 工作模式引擎 ★ → 08 AI助手
                                                    ↑
                                        核心，做不好其余都没意义

V2
  09 学习成长 → 10 个人档案 + 项目管理

V3
  11 生活与设备（以插件形式） → 12 插件系统 + 小组件 + 外部 Agent
```

> 04→05→07→06 的顺序理由：窗口管理是模式引擎的依赖，必须先有窗口控制能力，模式引擎才有意义。

## 三条贯穿全项目的设计原则

1. **本地优先** —— 数据在本机，V1/V2 无服务器，断网可用。
2. **单一写入者** —— SQLite 只由 Rust core 写，其他一切通过它。
3. **AI 只建议，用户来确认** —— 学习进度、个人档案，AI 不得自动修改。
