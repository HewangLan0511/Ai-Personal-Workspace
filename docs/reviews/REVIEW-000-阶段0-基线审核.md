## 四、发现的问题

### F-01 · 源计划书缺失（级别：一般）
**描述**：两份原始计划书 txt（`Personal Wrokspace  个人智能工作空间项目设计计划书 V1.0.txt`、`《Personal Workspace 智能工作空间》Agent开发执行计划书 V1.0.txt`）已不在工作区。
**影响**：失去需求追溯源头。后续若对指令条款产生歧义，无原始文档可比对。
**建议**：归档至 `docs/source/`，并在 `docs/agent-dev/README.md` 中登记来源。
**登记**：L-001

### F-02 · ADR-001 未定稿（级别：**严重** —— 阻塞阶段3）
**描述**：窗口控制与进程启动采用 Rust 还是 Python 尚未决策。`AGENTS.md` 中要求阶段1 定稿，但目前为空。
**影响**：直接阻塞阶段3（窗口管理）。若中途切换实现语言，已写的窗口相关代码全部作废。
**要求**：**阶段1 交付时必须包含 ADR-001 定稿文件**，否则阶段1 判定驳回。
**登记**：L-002

### F-03 · 缺少 .gitignore（级别：一般 —— 已修复）
**描述**：工作区无版本控制忽略规则，`node_modules` / `target` / `*.db` 存在入库风险（对应红线 V8）。
**处置**：监制已于 2026-09-12 补建 `.gitignore`，覆盖依赖、构建产物、数据库、密钥、日志。
**登记**：L-003（已关闭）

### F-04 · 门禁工具自身缺陷（级别：一般 —— 已修复）
**描述**：`tools/gate.py` 首轮运行产生 5 个 FAIL，全部为**工具自我误报**——脚本内的正则字面量与 `print` 输出被自己的规则命中。
**额外发现**：插件层数据库访问模式未覆盖 `require("sqlite3")` 写法，样本验证时漏检。
**处置**：修复三项（扫描豁免清单、findings 去重、插件数据库访问模式扩写），重测通过。
**意义**：这条证明了"自动门禁必须做对抗性验证"不是多余动作。

### F-05 · 无代码（级别：不适用）
**描述**：阶段1 尚未开工，符合当前项目进度阶段，非缺陷。
**记录理由**：明确"当前无代码能力验证"，避免后续误认为已通过功能验收。
