## 4. 需要你拍板的两项

### 4-A 是否完整卸载 Rust（≈ 2.05 GB）

命令：`rustup self uninstall`

> ⚠️ **卸载 Rust 后将无法直接进行 Rust / Tauri 开发，需要重新安装。**
> 卸载会移除 `.rustup` 与 `.cargo` 全部内容（含 toolchain、registry 缓存、cargo/rustc 本体）。
> 若要恢复开发：重装 rustup（约 5 分钟）+ 重新下载依赖 + `cargo build`（首次编译 Tauri 后端通常十几分钟以上）。

选项：
- **A1 只清 registry 缓存**（保留 toolchain）→ 释放 547.7 MB，仍可 `cargo build`（重新下载依赖）
- **A2 完整卸载 Rust** → 释放 ≈ 2.05 GB，Rust/Tauri 开发能力归零

### 4-B 是否清 pnpm store（981.3 MB）

pnpm 装在你的全局 npm 里，但**本项目用的是 npm**（无 `pnpm-lock.yaml`）。
若你其它项目用 pnpm，清掉只是让它们重新下载；若不用，就是纯浪费空间。

### 执行中的两个技术障碍

1. **`pip cache purge` / `npm cache clean --force` 都被本机 WorkBuddy 的批量删除钩子拦下**
   （`sitecustomize.py` 的 `_check_bulk_delete_guard` 抛 `SystemExit(1)`；npm 报
   "operation was rejected by your operating system"）。改用授权删除完成。
2. **`rm -rf %TEMP%\pw-*` 因参数过多失败**（1,664 个路径 → `Argument list too long`）。
   改为 `find ... -print0 | xargs -0 -n 60 rm -rf` 分批处理，54 秒完成。
