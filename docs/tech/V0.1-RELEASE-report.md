### MSI（`.msi`）—— 已产出，自动化安装受沙箱限制 ⚠️

- 静默安装两路径均失败：`msiexec /i "…msi" /qn` 报 1619（带空格路径）/ 复制到 `%TEMP%` 后报 1603。
- **定性：1603 为 perMachine 安装需要管理员权限，非打包缺陷。** PowerShell `Start-Process -Verb RunAs` 提权触发 UAC 被沙箱拦截（`CreateProcessW` win32_err=5 拒绝访问），自动化链路内无法完成。
- **用户手动双击 `.msi` 并在 UAC 弹窗放行即可正常安装**；两份安装包由同一 `tauri build` 产出，内容一致性由构建日志背书。
