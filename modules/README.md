# modules/ —— 第一方功能模块

业务逻辑与 UI，按主题切分。核心原则：

| 原则 | 说明 |
|------|------|
| 不依赖 plugins/ | 第一方模块与第三方插件互不影响 |
| 不写数据库 | 走 core HTTP 接口（/api/v1/* 或 Tauri command） |
| 不做窗口/进程控制 | ADR-001：交给 core |
