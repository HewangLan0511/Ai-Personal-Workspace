# 交接说明书：把这套设计交给实现模型

> ⚠️ **时效声明（2026-09-15）**：本文写于 UI-02~UI-08 批次之前，页面清单与部分交互已过期（如模型管理 `#/models`、档案编辑、工作空间状态栏等本文未覆盖）。
> **现状以 `docs/ui-handoff/` 六份交接文档为准**（ui-overview / ui-components / ui-pages / ui-interaction / ui-responsive / ui-forbidden），两者冲突时后者优先。
> 本文的价值是：五阶段实现顺序、可直接复制的实现 prompt、Token 抽取策略——这部分仍然有效。

> 目的：让另一个模型（或另一个会话的 Agent）**低成本、不跑偏**地把设计落地。
> 核心思路：**不要让实现模型一次性吃下 2000 行原型**。分阶段喂，每阶段给一个自包含的 prompt + 可勾选项的验收标准。

---

## 0. 三个文件各自的角色（先讲清楚，避免"全都读"）

| 文件 | 角色 | 实现模型怎么用 | 什么时候**不用**读 |
|---|---|---|---|
| `index.html` | **视觉与结构的事实来源**（像素、层级、交互、动效） | 照着对应页面实现；**里面的 CSS 就是组件库初稿，抽取复用，不要重写** | 不实现某个页面时，不要读那一页 |
| `tokens.css` | **Design Token 唯一事实来源** | 直接复制进项目 `src/styles/tokens.css`，一次到位 | 只需要读一次 |
| `design-system.md` | **规则**（组件规格 / 状态规范 / 适配 / 三级复杂度 / 禁止项） | 按阶段只读对应章节（§5 Token、§6 组件、§7 状态、§8 页面、§10 适配、§14 禁止项） | 不必全文喂，浪费 token |

**冲突时的优先级（写进 prompt 里）**：
1. 视觉与结构 → 以 `index.html` 为准
2. 规则与状态 → 以 `design-system.md` 为准
3. 都没覆盖 → 以「不违反 `design-system.md` §14 禁止项自检」为最高优先级

---

## 1. 最重要的一条省钱指令

> **原型的 CSS 就是组件库的初稿。让实现模型"抽取 + 适配"，不要"看截图重写"。**

`index.html` 里第 5–10 节 CSS 已经是按 Token 写的、命名语义化的组件样式（`.btn/.card/.app/.ws-card/.win/.ai-panel` …）。
实现模型只需：把这段 CSS 抽到项目的样式层 → 补上框架需要的 scoped/模块处理 → 微调。
这比让它对着视觉稿重新写一遍，**省一半以上的token，且不会跑偏**。

## 2. 实现顺序（5 个阶段，每阶段可独立验收）

| 阶段 | 范围 | 依赖 | 验收后可否先停 |
|---|---|---|---|
| **0** | Token + 应用外壳（标题栏 / 侧边栏 / 路由 / 工作台面板三层结构）**+ 全局 AI 侧栏** | 无 | ✅ 骨架对了，后面都是加速 |
| **1** | 首页 · 工作空间列表 | 0 | ✅ |
| **2** | 创建工作空间 · 软件页 · 添加软件抽屉 | 0 + 1 | ✅ |
| **3** | 工作空间运行界面 · 软件栏 · AI 侧边栏（**最核心**） | 0 | ⚠️ 这是产品成立与否的分水岭 |
| **4** | 学习 / 项目 / 档案 / 生活 / 设备 / 插件 / 设置（含开发者模式） | 0 | ✅ 可以最后做，不阻塞 |

**建议顺序：0 → 1 → 3 → 2 → 4。**
理由：阶段 3（运行界面）是产品成立的分水岭，越早验证越好；阶段 2 相对独立。

### 阶段 1 —— 首页 + 工作空间列表

```
接上一个任务。现在实现 Personal Workspace 的首页「我的工作台」与工作空间列表页。

【必读】
1. 【index.html】里 ROUTES.home 和 ROUTES.workspaces 两个函数（这是页面的 HTML 结构与文案，
   照抄文案，不要自己发挥）。
2. 【index.html】CSS 第 7 节 "首页 / 工作空间卡片"，直接抽取为组件样式。
3. 【design-system.md】§8 的 P0-1、P0-2 两节（线框与规格）。

【关键元素，缺一不可】
- 问候语**右侧的音乐条**（v1.1 新增）：46px 高，音乐图标(tint4) + 歌名(150px 省略) + 歌手(text-3)
  + 64px 细进度条 + 上一首/播放/下一首。默认**无背景无边框**，hover 才浮出 surface-2 ——
  它是氛围元素不是模块，不能抢 Display 标题。未播放时显示"没有正在播放 · 点这里开始"，不要隐藏。
  窗口 <1040px 隐藏。
- 首页 Hero「当前工作空间」：类型 emoji 标签 + 名称 + 应用 chips + 上次工作 + [继续工作] 主按钮
  + 右侧 Mini Map（工作空间的窗口排布缩略图）。这是首页最大视觉区域。
- Mini Map：一个用百分比绝对定位的小容器，数据来自工作空间的 layout:[{app,x,y,w,h}]。
  这是产品的视觉签名，必须实现，不能省略。
- 工作空间列表：12 列网格，卡片按使用频率分 size-l(6列)/m(3)/s(3)。右上角"自动/固定布局"切换。
  卡片 hover 才出现 [进入] 与 "…" 菜单。

【拖拽、右键与组件区 —— v1.3，规格见 design-system.md §4.1】
1. **工作空间卡片拖拽 = 交换位置 + 继承对方的视觉占比大小**。
   实现是：先 `swap(数组下标)`，再 `swap(两个元素的 size 字段)`。
   净效果 = 网格槽位尺寸固定、卡片换位置。不要做成"size 跟着对象走"，那样拖完网格布局会乱跳。
   **任何手动拖拽都自动把布局模式切成「固定布局」**（用户手动调过就必须尊重，不能被自动排序覆盖）。
   切换布局模式时**只改那两个按钮的 class**，不要整页重渲染。
1b. **★ 拖拽严禁整页重渲染（v1.3.1 硬约束）** —— 主人明确要求：拖完卡片主页整体位置不变，
   不能有"刷新了一下"的观感。落点后**只允许 DOM 局部换位**：
   - `swapSize(A,B)` 只把尺寸留在原槽位（`size-*` 这个 class token + 白名单里的尺寸型 inline style）；
     `flash(el)` 播放 460ms 纯 box-shadow 高亮（`.just-swap`，不改任何触发重排的属性）。
   - **★ 只换尺寸，其余参数跟着对象走**（v1.3.3）：明暗度（`filter:brightness()`、暗态 class）、
     不透明度、色调、角标、动效状态一律留在卡片自己身上，**不随槽位互换**。
     实现必须走白名单（`SIZE_CLASS_RE` / `SIZE_STYLE_PROPS`），
     **禁止写成 `a.className = b.className` 或整块搬 `style`** —— 那是"连人带衣服一起换"，
     会把对方的暗态和半透明换过来。
   - 回调 `onReorder(from,to)` **只能**做三件事：更新数据模型、**静默播报**、同步局部按钮 class。
     **绝不允许在回调里写 `render()`，也不允许重置 `scrollTop`。**
   - **拖拽不给 Toast**（v1.3.2）：结果肉眼可见，再弹居中提示条就是噪音。改走
     `announce(msg)` → 写进 `aria-live="polite"` 的 `.sr-only` 区，读屏念、屏幕不显示。
     Toast 只留给"删除/卸载/保存/恢复默认"这类元素会消失、需要告知结果的操作。
   - 播报文案说结果：`「A」与「B」已交换位置，A 现在是大卡片`（尺寸经 `sizeName()` 转人话）。
   - 插入排序场景（最近使用 / 组件区 / 抽屉编排行）用 `insertBefore` 局部搬移，同样不重渲染。
   - 参考实现见原型 `enableSort(container, itemSel, onReorder, mode)`，`mode='swap'` 走交换、否则走插入。
2. **最近使用的软件**拖拽 = 插入排序；**右键**出菜单：
   头部（对谁操作）→ 启动 / 添加到工作空间 / 在软件页显示 → 分隔 → 从最近使用中移除 → 分隔 → **高级设置…（永远置底）**。
   工作空间卡片右键同理：进入 / 重命名 / 复制 / 编辑应用 → 分隔 → 删除（danger）。
3. **组件区**（内容区与 AI 侧栏之间，224px）：用户自选的插件组件卡片，可拖拽排序，
   右上角 hover 出拖拽把手。空的时候**列要保留，只显示"＋ 添加组件"**，不能整列消失。
4. **自定义工作台抽屉**：首页问候语右上角一个 30px 图标按钮 + 组件区底部"＋ 添加组件"，
   两个入口进同一个抽屉。内容是：显示组件区总开关 / 组件排序与显隐 / 首页四个模块显隐 / 恢复默认。

【硬约束】
- 首页只有三个模块：Hero、最近使用、我的工作空间（+ 右侧「今天」）。禁止再加第四个模块。
- 拖拽反馈只用 opacity .35 + 2px 主色 outline，禁止位移动画与幽灵占位块以外的效果。
- **拖拽落点后禁止调用整页 render()**：滚动位置必须保持、入场动画不得重播、其他模块不得位移。
  这条不达标＝本次交付不合格（design-system.md §4.1 B+1）。
- 右键菜单的危险项不能放第一个；高级项必须置底。
- 组件区与首页模块必须成对实现"显示/隐藏"，隐藏后不能留塌陷的空白。
- 禁止出现"常用软件 0""暂无数据"这类空话，空态文案见 design-system.md §7.1。
- 最近使用必须显示真实软件名 + 图标，图标不小于 40px。

【验收】
- [ ] 首页第一屏（1440×900 不滚动）能看到：问候语、当前工作大卡、最近使用的软件
- [ ] 问候语右侧有音乐条，默认看不到背景，鼠标移上去才浮出浅底
- [ ] 内容区与 AI 侧栏之间有 224px 组件区，里面能看到天气/待办/正在播放
- [ ] 拖动组件卡片能换顺序，松手即生效
- [ ] 点"＋ 添加组件"或首页右上角的自定义图标 → 打开同一个抽屉，能开关模块与组件
- [ ] **反刷新自检**：先滚动首页到中段，拖动任意两张工作空间卡片交换 →

- [ ] 拖完卡片后右上角「自动/固定布局」自动切到「固定布局」，且切换过程不引起整页重绘
- [ ] **拖拽不弹 Toast**：拖工作空间卡片 / 最近使用 / 组件区 / 抽屉编排行，全程底部不出现任何提示条，

- [ ] 用读屏（或 DevTools → Accessibility）确认 `#liveRegion[aria-live=polite]` 有播报文本，

- [ ] 点音乐条的播放按钮，能在"播放中"和"没有正在播放"之间切换，切的时候布局不跳动

完成后只回复改了哪些文件 + 验收结果。

### 阶段 3 —— 运行界面 + 软件栏 + AI 侧边栏（**最高优先级**）

```
接上一个任务。这是整个产品最核心的界面，做不好产品就不成立，请重点对待。

【必读】
1. 【index.html】ROUTES.run 函数 + CSS 第 8 节 "工作空间运行界面" + initStage() 函数。
2. 【design-system.md】§8 的 P0-4。

【要实现】
- 进入即沉浸态：侧边栏图标化；顶部 56px 功能条 = 返回 + 工作空间名 + ●工作中(绿点呼吸)
  + [自动布局|手动调整] + [保存布局] + 时钟。
- 软件栏 46px：工作空间内的应用标签（VS Code/Chrome/终端/AI 助手）。选中项 brand-50 底。
  点击 = 把对应窗口置前并高亮。目标是替代 Alt+Tab。
- 主区「窗口编排画布」：底 #E9EBF0 + 22px 点阵。每个应用是一个白卡片窗口：
  32px 标题条(图标+名称+拖拽把手) + 内容区；hover 出现右下缩放手柄；选中态主色描边+3px 主色浅环。
- 三种布局状态：自动（按工作空间 layout 排布）/ 手动（自由拖动+缩放，拖动时自动从自动切为手动）
  / 保存布局（写回工作空间的 layout，按钮变成"✓ 布局已保存"）。
- **AI 助手不在运行界面内单独做一块**，用阶段 0 建好的全局 AI 侧栏：点软件栏的「AI 助手」tab
  = 展开全局侧栏 + 自动切到「工作区」模式；侧栏收起时舞台右下角出现浮动胶囊唤回。
  这样主区能全宽给窗口画布，AI 在所有页面位置一致。

【技术要点】
- 窗口用百分比定位（left/top/width/height: %），不要用 px——这样窗口 resize 时布局自动等比。
- 拖动的 mousemove/mouseup 用赋值式（document.onmousemove = fn），不要用 addEventListener，
  否则每次重渲染会累积监听器。
- 拖动时如果要切换布局模式，只更新按钮的 class，不要整页重渲染（会打断拖拽）。

【硬约束】
- 主区必须是"窗口编排画布"，不是一排软件按钮。
- AI 不是主角：默认可收起，宽度 320–380，不得占满主区。

【端到端验收（必须真的跑一遍）】

完成后回复：改了哪些文件 + 上面 5 条每一条的实际结果。任何一条没做到，直接说明卡在哪。

## 6. 我预判的 5 个跑偏点（实现完重点看这几处）

1. **卡片描边变深** → 一眼回到后台管理。看首页 Hero 和工作空间卡片。
2. **Mini Map 被省略** → 工作空间卡片变成"图标+文字"的普通卡片，产品失去辨识度。
3. **运行界面做成软件启动器** → 只有一排按钮，没有窗口编排画布。
4. **添加软件抽屉又变回表单** → 名称/路径/参数/分类四个输入框回来。
5. **开发者信息外泄** → 某个页面角落里出现 Endpoint、Capability 之类的字样。全局搜一遍这四个词就行。
