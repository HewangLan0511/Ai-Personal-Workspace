# UI 总览 · Personal Workspace

> 交接文档 1/6。代码载体：`personal-workspace-ui/index.html`（单文件原型：内联 CSS + 单 `<script>`）。
> 配套规范源：`motion-system.md` / `design-system.md` / `tokens.css` / `skin-system.md` / `default-skin.md`。
> 本文描述的是**已完成定稿**的最终形态；技术 Agent 接手时以此为基线，改动前先读 `ui-forbidden.md`。

## 1. 产品定位

**个人工作台（Personal Workspace）**：单用户、本地优先的桌面效率环境。

- 核心叙事：「进入的是一个有目标、应用集合与布局状态的工作环境」，不是应用启动器，也不是后台管理台。
- 三条产品主线：**工作**（工作空间 / 窗口编排 / 工作模式）、**学习**（目标 + 路线）、**生活**（插件化信息卡）。
- AI 是常驻伙伴而非功能页：全局右侧 AI 侧栏（dock）在任何页面都存在；AI 助手页提供聊天与工作空间助手双模式。
- 语气与视觉：工作台风格 —— 圆角卡片、浅色底、克制动效、无表格化后台感；所有数据本地内存态，无账号系统、无云端。

## 2. 全局结构（Shell）

```
┌──────────────────────────────────────────────────────┐
│ Sidebar（导航） │        View（内容区）        │ AI Dock │ Widget Col │
│  约 220px      │   page-head + 页面内容        │ 360/48  │  约 260px  │
└──────────────────────────────────────────────────────┘
```

- **Sidebar**：分组导航（首页 / 工作[工作空间·软件] / 学习 / 项目 / 生活 / [AI 助手·设备·档案·插件]）+ 底部设置与设备状态。工作模式（cinema）下自动收窄为图标态。
- **AI Dock**：全局常驻。展开 360px（聊天 / 工作空间助手双模式），收起为 48px 竖条入口。极限宽度下强制竖条。
- **Widget Col（组件区）**：仅首页出现，天气/待办/正在播放等侧挂小卡，可开关与排序；COMPACT 以下整体让路（增值区，非核心结构）。
- **Toast Host**：底部居中，最多 2 条，超额挤旧，点击可关。
- **Layer**：全局弹层容器（scrim + modal / drawer / 右键菜单），统一退场动画（先 `.out` 再清空）。

## 4. 不允许破坏的设计原则（红线摘要，详见 ui-forbidden.md）

1. **S2 局部 diff 纪律**：页面内状态变化只重写目标叶子容器，禁止整页重绘；判据是 DOM 节点身份。
2. **Motion Token 双维度**：Duration 与 Intensity 独立，禁止相乘；降级三档（完整/减弱/关闭）靠变量覆盖，不 `!important` 归零。
3. **工作台定位**：不做后台管理风格、不引入表格化表单页、不新增无意义页面。
4. **首页内容完整优先**：任何宽度下不得出现标题竖排、模块互相挤压；收紧策略是"堆叠"而不是"删除"。
5. **工作模式 1:1 跟手**：窗口拖拽绝不能带过渡；吸附只在松手时落位。
6. **皮肤运行时不动**：Skin Runtime 与 Motion 系统已冻结，页面级改动不得触碰。

## 5. 状态与数据总原则

- 全部数据为内存 mock（`state` 对象），无数据库、无账号、无持久化。
- 每个功能域有自己的 state 命名空间：`state.run`（工作模式）、`state.models`（模型）、`state.profile`（档案）、`state.wfModes`（工作模式模板）、`state.lifeSlots`（生活槽位）等。
- 未来 Runtime 接入原则：**只替换数据读写点，不改编译好的 UI 骨架与刷新路径**（各域接入口见对应文档与 ui-components.md 末尾）。
