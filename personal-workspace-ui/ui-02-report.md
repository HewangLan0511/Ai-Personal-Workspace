# UI-02 实施报告 · 产品视觉定位修正

依据：`default-ui-review.md` 巡检结果（P0×2 + P1×4，共 6 项）。
范围纪律：不新增功能、不改信息架构、不改技术架构；只调整已有组件的位置、权重、视觉焦点和交互表达。
验收状态：`node`+`vm.Script` 语法通过；`verify_s2_local_diff.py` **6/6**；`verify_collapse_expand.py` **7/7**。

---

## 1. 修改前后对比说明

### P0-1 首页右侧「今天」→「今日行动中心」

| 维度 | 修改前 | 修改后 |
|---|---|---|
| 内容语言 | 设备监控语言：使用时长 spark 图、CPU/内存占用行 | 行动语言：今日任务（checkbox 列表，chip「1/3 完成」）、最近工作（AI 项目开发 + 继续按钮）、学习进度（Python 异步编程 · 80%）、待处理（微信 3 / QQ 1） |
| 设备信息 | 与任务并列的实心卡片，权重等同 | 降级为 `card--ghost` 幽灵条目：「我的设备 · Windows PC · 今日使用 3 小时 24 分」，一行带过 |
| 定位判断 | 像 PC 管家 / 系统监控面板，破坏个人工作台定位 | 回到「今天我要做什么」的工作座舱视角 |

### P0-2 首页视觉焦点

| 维度 | 修改前 | 修改后 |
|---|---|---|
| 问候语 | `t-display`（页面最大字号），与 Hero 抢焦点 | 降为 `t-page`，与页面标题同级 |
| 双焦点 | 问候语 + 「继续工作」两个视觉入口 | Hero 唯一主动作：继续工作；问候语下方合并副行「9 月 13 日 · 星期日 · 准备开始什么？」，原独立 section 标题「准备开始什么？」删除 |

### P1-3 工作模式窗口拖动反馈

- 修改前：窗口拖动松手后无任何反馈，缺少空间确认。
- 修改后：`onMove` 记录 `drag.moved`，`onUp` 时若确实移动过则对窗口调用 `flash()`——复用已有的 `just-swap` 类 + `swapFlash` 动画 + `--mt-dur-highlight` token。拖过即高亮一瞬，未拖（纯点击）不闪。无对齐线、无磁吸、无新拖动系统。

### P1-4 项目页横幅

- 修改前：120px 装饰性 SVG 插画，与产品语言无关。
- 修改后：复用 `minimap()` 组件渲染「AI 项目开发」工作空间的真实布局（`surface-1` 底），横幅从「配图」变成「空间的缩略地图」，与工作台语言一致。

### P1-5 插件页 CTA 降级

- 修改前：主按钮 `btn--primary`「可发现 / 推荐」文案，应用商店感。
- 修改后：降为 `btn--secondary`；文案改「更多组件 / 可用」，弱化「去获取」的诱导，强调「可用性清单」。

### P1-6 生活区权重重排

- 修改前：4 列平均分配，所有卡片权重相同。
- 修改后：按使用频率分级——今日使用（span2，首位）、天气（1 列）、消息（1 列）、正在播放（span2）、连接更多（span2，dashed 幽灵样式收尾）。

## 4. 哪些设计原则被保留

1. **S2 局部更新纪律**：本轮所有改动都在各页面渲染函数内部，未新增任何整页重绘路径；改动后 `verify_s2_local_diff.py` 6/6 通过（DOM 节点身份判据）。
2. **Motion Token 双维度独立**：未触碰 Duration/Intensity 任何 token；降级三档（standard/reduced/off）机制原样。
3. **复用优先**：P1-3 用现成 `flash()`+`just-swap`；P1-4 用现成 `minimap()`；P0-1 幽灵条目用现成 `card--ghost`；任务清单用现成 checkbox 样式。没有为任何一个改动新造组件体系。
4. **信息架构不动**：页面数量、路由、卡片归属页面均未变——只换了内容权重和表达语言。
5. **折叠/展开交互**（上一阶段成果）不受影响：`verify_collapse_expand.py` 7/7 通过。
6. **工作台定位标尺**：高频（任务/最近工作/AI）前置放大、低频（设备/插件获取/生活低频卡）后置弱化，与 review 报告的模块权重结论一一对应。

## 5. 不新增 token、不新增动画的确认

- **Token：0 新增。** 未在 `:root` / token 区添加任何 CSS 变量；`--mt-dist-page` 等出现仅为既有定义（grep 确认为原有行）。
- **动画：0 新增。** 未添加任何 `@keyframes`、未新增任何 transition 声明；P1-3 的高亮完全来自既有 `swapFlash` 动画经 `flash()` 触发。
- 全部改动为：class 替换（`t-display→t-page`、`btn--primary→btn--secondary`、`card→card card--ghost`）、DOM 结构重排、文案修改、以及两处 JS 行为（`drag.moved` 标记 + `flash()` 调用）。
