# UI-04-A 实施报告 · 真实体验优化第一批

范围：任务 1 学习目标管理 / 任务 2 AI 助手页面重构 / 任务 3 设备中心入口 / 任务 4 工作模式窗口调整大小。
约束遵守：信息架构与三栏思想不动（设备入口为任务明确要求的新增）、无新动画体系、无新 Motion Token、
Skin Runtime 未动、路由仅新增任务要求的 `#/device`（导航原来没有入口，首页 ghost 卡本来就是死链接）。
说明：本项目载体是可交互原型，任务 4 的 resize handle / geometry / 保存布局在原型内实现用于 UI 确认；
真实产品中的 pointer resize 与持久化仍按任务书留给技术 Agent。

## 任务 1 · 学习页目标管理

**修改前**：学习页只有课程进度卡 + 学习路线时间线，目标是写死在卡片里的一行小字——展示页。
**修改后**：页头下新增「当前目标」卡：target 图标 + 目标名称（Python 视觉算法工程师）+ 类型 chip +
当前水平/目标时间一行摘要 + `[修改目标]` `[重新规划路线]` 两个次级按钮。
- 修改目标 → **复用既有抽屉（drawer/scrim）模式**：目标名称（输入）、类型（分段：职业方向/技能提升/兴趣学习）、
  当前水平（输入）、目标时间（分段：3/6/12 个月），底部 `AI 重新规划`（ghost）+ 取消 + 保存。
- 保存 → 更新 state → 页面刷新 → toast「学习目标已更新」；AI 重新规划 → toast 模拟（原型约定）。
- 新增组件：goal 卡（复用 card/app/chip/btn）、goal 编辑抽屉（复用 drawer-head/body/foot、field、input、seg）。

## 任务 2 · AI 助手页面重构（导航进入的完整页，非右侧 dock）

**修改前**：页头 + 模式 tab + 权限卡 + `min-height:340px` 的小聊天卡——下半屏大量空白，视觉中心不在对话。
**修改后**：
```
页头（标题+定位语 | 模式tab | 模型选择）
历史会话(264px) |        聊天区域(1fr)
                |  权限行（chat=锁提示 / ws=已授权+管理）
                |  消息流（flex:1 滚动，视觉中心）
                |  建议 chips（ws）+ 输入行（贴底）
```
- 会话列表：4 条内存 mock 会话（按模式分组显示），点击切换会话（消息流随之切换）；
- 模式切换（聊天/工作空间助手）保留既有 `ai-tab` 语义，切换后自动选中该模式第一条会话；
- `.ai-chat` 高度 `min-height:calc(100vh - 300px)` + 消息区 flex 滚动 → **进入页面视觉中心即聊天区域**；
- 复用：card / tabs / live / msg / bubble / ai-suggest / input / select / chip，零新组件体系；
- 新增 CSS 仅布局类（ai-grid / ai-sessions / ai-session / ai-chat / ai-msgs），全部引用既有间距/颜色 token。

## 任务 3 · 设备中心入口

**修改前**：设备页（ROUTES.device）存在但导航无入口——首页 ghost 卡的 `data-r="device"` 是**死链接**。
**修改后**：
- 导航 divider 区新增「设备」（monitor 图标，位于 AI 助手之后）；
- 页面升级为**设备中心**：标题改「设备中心 · 查看与管理」；保留本机状态（CPU/内存/GPU/磁盘 metric）与今日使用；
  新增「系统状态」行组（系统版本/开机时长/安全状态/检查更新，复用 setRow）；新增「连接更多设备」dashed 卡（规划中占位）；
- 原则落地：**首页=状态展示（ghost 一行），设备页=查看管理**，没有管理后台化的系统控制。

## 任务 4 · 工作模式窗口调整大小

**修改前**：仅右下角 16px grip 可缩放（无方向、无边界、无反馈、无最小尺寸），布局"保存"按钮只切假状态。
**修改后**：
1. **缩放热区（affordance）**：每窗 8 个不可见热区（四边 6px + 四角 14px），只做光标暗示（ns/ew/nesw/nwse-resize）；
   右下角既有 grip 图标保留为视觉暗示——无新增可见元素；
2. **resizing 状态反馈**：过程复用拖动语言——`carried`（shadow-lg 抬起 + brand 边框）+ `carrying`（其余窗口退后）；
   右上角出现**等宽字体尺寸 HUD**（如 `1280 × 720`），跟手实时更新，**松手即淡出**（`--dur-micro`）不持续显示；
3. **响应规则**：最小 `320 × 200 px`（西/北向拖动时对边固定、位置自动补偿）；越界夹紧到舞台内（left/top ≥0，右/下不溢出）；
4. **布局保存**：`保存布局` 现在真实从 DOM 读回各窗几何存入 `state.run.customLayout`，render 按保存几何重建；
   新增 `[恢复默认]`（清空 customLayout）；`自动排列` 同时清除已存布局——三个入口语义闭环：
   挪/缩窗口 → 保存 → 进出工作模式保持；恢复默认/自动排列 → 回默认。

## 2. 新增组件列表

- **新增**：学习目标卡、目标编辑抽屉、AI 会话列表（`.ai-sessions/.ai-session`）、AI 聊天主区布局（`.ai-grid/.ai-chat/.ai-msgs`）、窗口 resize 热区（`.rz-*`）、尺寸 HUD（`.win-size`）、设备系统状态组、连接设备占位卡。
- **删除**：AI 页旧的单卡布局、设备页旧标题；无功能删除。
- **复用**：drawer/scrim/field/input/seg（目标编辑）、card/tabs/msg/bubble/live/chip（AI 页）、metric/setRow/badge/dashed（设备页）、carried/carrying/flash/just-swap（resize 反馈）、stage-hint。

## 3. 设计原则确认

- ✅ 工作台定位：学习=推进主线、AI=工作区、设备=查看管理、窗口=受控桌面；没有出现管理后台语言；
- ✅ 反管理后台化：设备页全部为只读行 + 幽灵占位，无系统控制项；学习编辑走抽屉不走表单页；
- ✅ 反信息堆叠：AI 页左右分工明确（列表窄列、对话主体）；学习页目标卡单行摘要不展开细节；
- ✅ 不新增动画体系/token：resize 反馈全复用 carried/carrying/flash，HUD 淡出用 `--dur-micro`，抽屉/弹层走既有 drawer/modal 路径。
